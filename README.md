# دعوة زفاف محمود و شروق — ١٠ مارس ٢٠٢٧

موقع دعوة تفاعلي (HTML/CSS/JS صافي بدون أي أدوات بناء). بيشتغل على GitHub Pages مباشرة.

## المزايا
- مظروف بختم شمع (صورة حقيقية): لمسة على الختم → وهج ذهبي + المظروف يفتح + الموسيقى تبدأ.
- مشهد الغلاف (قوس + مسجد + العروسين) صورة حقيقية، والأسماء والتاريخ نص فوق السماء، مع بارالاكس خفيف وغبار ضوئي ولمعان الفوانيس والشمس.
- كروت تاريخ بتتكشف بالمسح (Scratch)، جدول زمني، عدّاد تنازلي لحظي، خريطة جوجل، فورم تأكيد حضور.
- عربي (افتراضي) + إنجليزي: زرار اللغة فوق، أو الرابط `?lang=en`.
- لوحة خاصة `admin.html` — العريس فقط يشوف الردود والتهاني (محمية بحساب جوجل + قواعد Firestore).

## تجربة محلية
```bash
python -m http.server 5173
# افتح http://localhost:5173
```
(`#open` في آخر الرابط بيتخطى المظروف: `http://localhost:5173/#open`)

## تعديل البيانات
كل التواريخ والمواعيد والمكان في **`js/config.js`**، والنصوص في **`js/i18n.js`**.

## صور المظروف والغلاف
في `assets/img/` (نسختين: WebP + JPG احتياطي): `envelope-closed` و`envelope-open` و`hero`، كلها 9:16. لو عايز تبدلها حط صور بنفس النسبة والأسماء. مكان الختم في الصورة (50% / 50.5%) وسماء القوس اللي عليها الاسم في `css/style.css` (`.seal-hit` و`.hero-text`).

## الصور الواقعية (assets/img) والمصادر
- **`source-images/`** = الصور الخام اللي اتولّدت (للأرشيف فقط — مش بيتحمّل في الموقع، وممكن ما تترفعش على GitHub).
- **`assets/img/`** = النسخ المحسّنة اللي الموقع بيستخدمها (WebP). أي ملف ناقص بيتخفي لوحده والصفحة مبتبوظش.

| الملف | بيظهر فين |
|---|---|
| `envelope-closed` / `envelope-open` / `hero` (`.webp` + `.jpg`) | المظروف والغلاف |
| `paper.webp` | خلفية ورق التوت العاجي (بلاطة متصلة متكررة) |
| `gold-foil.webp` | رقاقة الذهب فوق كروت المسح |
| `bouquet-tl.webp` / `bouquet-br.webp` | باقات ورد في زوايا قسم الشكر وتأكيد الحضور |
| `garland.webp` | إكليل الورد بين الأقسام |
| `divider-gold.webp` | بروش الذهب كفاصل بين الأقسام |
| `scene-gate.webp` / `scene-couple.webp` | صور الجدول الزمني (٧:٠٠ وصول الحضور، ٨:٠٠ دخول العروسين) |

الباقات والإكليل والبروش متصورين على قماش مش شفاف، فاتعملّهم "تسوية خلفية" (القماش يبقى أبيض) وتخفيت حواف، والموقع بيدمجهم فوق الورق بـ `mix-blend-mode: multiply` فمفيش مستطيل ظاهر. ولو غيّرت صورة منهم: `python tools/process_assets.py` بيعيد توليد كل الملفات من `source-images/`.
صورة `couple-greenscreen.jpg` ما اتستخدمتش: حافة الطرحة الشفافة بتطلع خضراء بعد القص.

### أداة قص الخلفية الخضراء (اختيارية) `tools/chroma_key.py`
```bash
python tools/chroma_key.py raw/image.jpg -o assets/img
```
بتحوّل صورة خلفيتها `#00FF00` لـ PNG شفاف بحواف نضيفة. محتاجة Pillow بس.

## الموسيقى (أكتر من أغنية)
حط ملفات الأغاني (MP3 أو M4A) في `assets/music/` وسجّلها في `music.tracks` داخل `js/config.js` (الأسماء والعناوين بالعربي والإنجليزي). الأولى بتشتغل مع فتح المظروف. لو فيه أكتر من أغنية بيظهر زرار «التالية» جنب زرار الموسيقى، وكل أغنية لما تخلص بتشتغل اللي بعدها. أي ملف ناقص بيتجاهل، ولو مفيش ولا ملف زرار الموسيقى بيتخفي.

## الرجوع للمظروف
زرار المظروف الصغير فوق (عكس زرار اللغة) بيرجّع المظروف مقفول عشان تضغط على الختم تاني. الموسيقى بتفضل شغالة.

## صور القاعة
حط الصور في `assets/venue/` وضيف أسماءها في `venue.photos` داخل `js/config.js`. القسم بيظهر تلقائيًا.

## تفعيل تأكيد الحضور (Firebase — مجاني)
بدون الخطوات دي الفورم بيشتغل في «وضع التجربة» (الردود بتتخزن في متصفح الزائر بس).

1. ادخل <https://console.firebase.google.com> → **Add project** (اسم أي حاجة، مفيش داعي لـ Analytics).
2. **Build → Firestore Database → Create database** (production mode، أي منطقة قريبة).
3. **Build → Authentication → Get started → Sign-in method → Google → Enable**.
4. **Authentication → Settings → Authorized domains** → أضف نطاق موقعك (مثلًا `username.github.io`).
5. **Project settings (⚙) → Your apps → Web `</>`** → سجّل التطبيق وانسخ قيم `firebaseConfig` والصقها في `js/firebase-config.js`، واكتب إيميل جوجل بتاعك في `ADMIN_EMAIL`.
6. **Firestore → Rules**: الصق محتوى `firestore.rules` بعد ما تغيّر `PUT-YOUR-GMAIL-HERE@gmail.com` لإيميلك → **Publish**.
7. افتح `https://<موقعك>/admin.html` وسجّل الدخول بحساب جوجل بتاعك.

**الأمان:** أي زائر يقدر *يضيف* رد بس بشكل محدد، لكن *القراءة والحذف* مسموحة لإيميلك فقط من قواعد Firestore — حتى لو حد عرف رابط `admin.html` مش هيشوف حاجة.

## النشر على GitHub Pages
> مجلدا `tools/` و`source-images/` للاستخدام المحلي بس — مش مطلوب يترفعوا مع الموقع (ممكن تضيفهم في `.gitignore` أو تسيبهم، مش بيأثروا).

1. ارفع المجلد كله على مستودع GitHub.
2. **Settings → Pages → Deploy from a branch → `main` / root**.
3. الرابط هيكون `https://<username>.github.io/<repo>/`.
